## Recommended MVP

1. Super admin can onboard mandals.
2. Mandal admin can upload a vargani slip template and configure fields.
3. Mandal admin can create members and groups.
4. Members can collect vargani and generate slips from mobile.
5. Dashboards show collection by mandal, group, member, area, date, payment mode, and expense summary.
